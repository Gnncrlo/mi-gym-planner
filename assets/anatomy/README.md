# Mapa muscular

`muscle-atlas.png` es una ilustración anatómica generada para esta aplicación. Se usa como base frontal/posterior del mapa de regiones definido en `muscle-atlas.js`. No se presenta como una fotografía del ejercicio ni como una medición de activación. Los colores se renderizan como superposiciones SVG; la imagen original permanece sin modificar.

Las fotografías de técnica se mantienen en `assets/exercises/` con su licencia y fuentes originales. El mapa es una orientación de zonas; no muestra todos los músculos profundos y no demuestra aislamiento de un músculo.
